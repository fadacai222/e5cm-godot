# E5CM 新功能开发计划

本目录用于把 E5CM 从“完整可玩的街机音游重制版”扩展为“具有长期目标、技术训练、玩家表达和赛季竞争能力的现代音游”。

当前阶段仅编写产品与技术方案，不修改游戏业务代码。所有实现必须继续遵守现有项目的原版街机 UI、离线优先、外置曲库、低风险增量开发和自动化测试原则。

## 推荐开发顺序

1. `00-总路线图与共享基础设施`
2. `06-智能歌单与随机轮盘`
3. `02-每日周常挑战`
4. `09-奖励与玩家表达系统`
5. `01-训练室与判定分析`
6. `03-个人最佳鬼影`
7. `05-三首挑战路线与街机爬塔`
8. `04-派对模式`
9. `07-DIY曲包管理中心`
10. `08-WEF赛季联赛`

这个顺序不是按“看起来最酷”排列，而是按共享数据依赖、开发风险和玩家收益排序。智能歌单、挑战与奖励可以先形成一个完整的长期循环；训练室和鬼影共用判定事件记录；爬塔与派对依赖更稳定的规则修饰器；WEF 最后接入，避免过早陷入服务端和反作弊。

## 通用完成标准

每个功能只有同时满足以下条件才算完成：

- [ ] 有独立开关或版本迁移，旧存档可以正常加载。
- [ ] 新增存档使用版本字段，损坏数据可回退到默认值。
- [ ] 不阻塞启动、选歌和进入游戏主流程。
- [ ] 在无网络状态下有明确行为，不得永久等待。
- [ ] 关键计算逻辑有 Godot 自动化测试。
- [ ] UI 遵循 `skills/original-arcade-ui/SKILL.md`，不使用默认 Godot 皮肤。
- [ ] 1920×1080 逻辑画布、低分辨率窗口和高 DPI 均不溢出。
- [ ] 性能模式关闭高成本装饰后，核心功能仍完整可用。
- [ ] 发生异常时记录可诊断日志，但不把玩家卡死在场景中。
- [ ] 发布包资源探针和完整自动化测试通过。

## 明确暂缓

以下方向暂不进入近期开发：

- 实时联网对战：延迟、断线、谱面版本和作弊成本过高。
- 完整金币商城：奖励库存不足时只会制造无意义货币。
- AI 自动谱面直接发布：只能作为编辑草稿，不能绕过人工验收。
- 无上限叠加全屏特效：会遮挡判定区、降低可读性并引发性能和光敏风险。

## 文档使用方式

每个专题包含：

- `实现方案.md`：产品目标、用户流程、数据结构、技术架构、风险和验收标准。
- `TODO.md`：按依赖顺序拆分的可执行任务，后续实现时逐项勾选。

实现任何专题前，先检查 `00-总路线图与共享基础设施` 中的共享契约是否已经落地。
