# 训练室与判定分析实现方案

> 最终实施状态（2026-07-20）：本文规划已全部落地。训练入口暂时位于大模式选择页；训练设置、片段循环、动态 BPM、失误回退、正式对局分析、长期趋势、结算全屏分析和问题片段直达训练均已完成，并通过全模式与 Windows 发行验证。

## 1. 功能定位

训练室不是“再加一个 autoplay”，而是让玩家能定位问题、缩短重复练习成本并验证校准设置。目标用户包括：

- 想冲全连、全 P 的熟练玩家。
- 因某一小段反复断连的玩家。
- 不确定自己是早按还是晚按的新玩家。
- 需要测试新键位、箭头皮肤和谱面兼容性的开发者。

成功标准：玩家打完一局后，能明确知道最薄弱轨道、最容易断连时间段和稳定偏移趋势，并可一键进入对应片段练习。

## 2. MVP 范围

### 2.1 训练入口

当前版本在大模式选择页增加“训练室”入口。开启后继续使用现有大模式 → 玩法 → 选歌流程，确认歌曲后进入独立训练设置页：

- 练习范围：整首 / 自定义起点终点 / 结算识别出的高风险问题片段。
- 播放速度：50%、75%、90%、100%。
- 循环次数：无限 / 3 / 5 / 10。
- 失误自动回退：关闭 / 3 秒 / 5 秒。
- 节拍器：关闭 / 全程；按谱面动态 BPM 时间轴计算节拍与预备时间。
- 是否显示实时 Early/Late。

MVP 不允许训练成绩进入正式最高分、经验、每日挑战或赛季。

### 2.2 判定分析

每次正式或训练对局记录轻量判定事件：

```gdscript
{
  "note_index": 42,
  "track": 3,
  "type": "tap",
  "target_ms": 45120,
  "diff_ms": -18.4,
  "judge": "perfect",
  "combo_after": 87
}
```

聚合输出：

- 每轨道 Perfect/Cool/Good/Miss。
- 每轨道平均偏移、中位数偏移、标准差。
- Early / Late 数量和占比。
- 连续失误区间。
- 最差 3 个 5 秒窗口。
- Hold 头、持续、尾的异常统计。
- 过滤极端离群值后的校准建议。

### 2.3 结果页

结算页新增“判定分析”按钮，打开独立全屏面板：

1. 总览：准确率、平均偏移、稳定性。
2. 轨道：按真实判定系统显示 5 轨，或 10 轨时显示 1P/2P 各 5 轨。手键动画不是可计分判定事件，不伪造统计。
3. 时间轴：歌曲时间轴上的失误峰值。
4. 建议：偏移建议和可练习片段。

点击某个失误区间可直接进入训练室，并自动设置片段范围。

## 3. 数据与算法

### 3.1 数据保存

正式对局默认只持久化聚合结果，不永久保存全部逐音符事件，避免历史数据膨胀。

建议：

```text
user://feature_data/analytics_v1.json
```

按 `chart_hash` 保存最近 N 次聚合和生涯聚合：

- 最近 10 局。
- 总游玩局数。
- 每轨道累计判定。
- 偏移指数移动平均。
- 最佳准确率、最低 Miss。

逐音符事件仅用于：

- 当前结算分析。
- 最近一次对局复盘。
- 鬼影录制。

### 3.2 偏移建议

不要用单局平均值直接建议修改设置。建议满足：

- 至少 3 局正式成绩。
- 每局有效判定不少于 100 个。
- 排除 Miss 和绝对偏差超出判定窗的事件。
- 使用中位数或截尾平均值。
- 多局趋势方向一致。

显示方式：

```text
最近 5 局有效样本：1248
稳定晚按：中位数 +16ms
可尝试将谱面偏移从 0ms 调整到 -10ms
置信度：中
```

只提供建议，不自动修改。

### 3.3 最差片段识别

把歌曲划分为 5 秒滑动窗口，步长 1 秒；损失权重建议：

- Perfect：0
- Cool：1
- Good：3
- Miss：8
- 断 Hold：8

窗口分数相同时优先：Miss 更多、Combo 损失更大、位置更靠前。相邻高风险窗口合并，避免给出三个几乎相同的片段。

- `tests/test_training_analytics_completion_20260720.gd`：算法、趋势、存档、动态 BPM。

- `tests/test_training_exit_paths_20260720.gd`：片段、音频、主动退出清理。

### 修改点

- `core/judge_system.gd`：保证判定报告有稳定 note_index 和目标时间。
- `scenes/gameplay/gameplay.gd`：发布判定事件、应用训练时间段和速度。
- `scenes/gameplay/conductor.gd`：支持安全 seek、变速和循环边界。
- `scenes/settlement/settlement.gd`：增加分析入口，不改变当前结算主时间线。
- `scenes/mode_select/mode_select.gd`：当前阶段增加训练室入口。
- `scenes/song_select/song_select.gd`：训练武装状态下把歌曲确认路由到训练设置页。

## 5. 训练播放技术难点

### 5.1 音频变速

Godot 内置音频变速可能改变音高。必须明确选一种：

- MVP：允许变调，文案明确“训练速度会改变音高”。
- 增强版：使用支持 time stretch 的音频处理方案保持音高。

不要为了保音高先引入不稳定原生插件，优先把训练闭环做通。

### 5.2 Seek 一致性

每次循环重置必须同步：

- 音频位置。
- Conductor 时钟。
- JudgeSystem 已判定状态。
- NoteField 可见音符。
- Combo、血量和实时统计。
- 背景动画状态。

建议新增“片段重建”接口，而不是手工修改多个私有字段。

### 5.3 预备拍

片段从 60 秒开始时，先在 57～60 秒显示预备拍，但不得判定旧音符。预备拍长度按当前 BPM 计算，至少 2 拍，最多 4 拍。

## 6. 非目标

- 不做完整谱面编辑器。
- 不允许训练成绩计入正式记录。
- 不自动修改玩家偏移设置。
- MVP 不保存无限历史逐音符日志。
- MVP 不承诺所有音频格式保音高变速。

## 7. 验收标准

- 能从大模式训练入口选歌，也能从结算问题区间直接进入训练。
- 自定义片段连续循环 50 次，起点与音符不累计漂移。
- 速度不是 100% 时，成绩明确标为训练并被资格系统拒绝。
- 真实 5/10 计分轨道统计总数与 ScoreSystem 判定总数一致。
- Early/Late 正负方向有单元测试，不能显示反。
- 偏移建议不足样本时明确显示“不足以判断”。
- 分析页面在 1P、2P、情侣谱面下不越界。
- 退出训练后恢复原速度、偏移和正常对局流程。

## 8. 风险与回滚

| 风险 | 影响 | 应对 |
|---|---|---|
| Seek 后判定状态残留 | 重复 Miss 或幽灵音符 | 统一片段重建接口，增加循环 50 次测试 |
| 变速导致音画漂移 | 训练不可用 | Conductor 统一以实际音频时钟为准 |
| 分析数据太重 | 结算卡顿 | 聚合放在纯算法中，逐音符仅内存保存 |
| 偏移建议误导 | 玩家越调越差 | 多局门槛、置信度、仅建议不自动应用 |
| 分析 UI 遮挡结算动画 | 视觉回归 | 结算完成后才允许打开独立页 |

回滚时可关闭训练和分析入口；正式对局与当前结算载荷保持兼容。
