# 实施计划：原版街机 UI 统一重构

## 目标

以用户提供的原版 1920×1080 截图和 `D:\E5CM-CG` 原项目设置页实现为基准，把 Godot 项目的系统弹层统一到同一套街机 HUD 视觉语言。重点覆盖全部 ESC 菜单、选歌右上角玩家信息、歌曲搜索菜单、玩法/星级筛选菜单，并建立可复用的主题组件，避免继续逐页硬编码。

## 原版视觉规则

1. 深海军蓝半透明底，不使用普通桌面软件式灰卡片。
2. 青色为主结构光，洋红为辅助定位光，金黄只表示选中、VIP、等级和关键数值。
3. 面板以切角、折线、细描边、内框和扫描线构成；禁止大圆角、大阴影、通用 AI 渐变卡片。
4. 信息层级采用“中文主标题 + 小号英文/状态副标题 + 数值强调”，数据使用稳定宽度布局。
5. 头像保持原色；玩家信息横向展开，包含昵称、等级、段位和状态标识。
6. 弹层打开使用短促的缩放、位移和淡入，不使用缓慢网页式动画。
7. 所有交互保留鼠标、键盘、ESC、左右方向和原有状态同步逻辑。
