# 实施计划：DIY 特效谱兼容补丁与头像亮度修复

## 目标

把 `D:\E5CM-CG` 原项目已验证过的 JSON 特效谱保护规则迁移到 Godot 项目，并修复 Gameplay HUD 与 ESC 用户信息头像发黑发暗的问题。所有修复以“规则化、可测试、默认安全”为准，不使用按歌曲名硬编码作为主方案。

## 已确认的原项目规则

1. **总时长与事件时间轴分离**：末尾 `<1 BPM` 只有在会额外制造至少 30 秒异常尾段时，才从“总时长估算时间轴”剔除；真实事件时间轴保留作者变速。
2. **音频时长是最终边界**：倒计时、结算和可计分事件不能无限超过实际音频。
3. **超极端 BPM 特效段**：`>=1,000,000 BPM` 可能用于压缩假音符视觉演出，不应导致无穷时长或数值溢出。
4. **假音符不参与判定**：`isFaked=true` 只能渲染，禁止进入分数、Combo、HP 与结算统计。
5. **非法数据安全化**：非有限 BPM、非正 BPM、负行号、负 Hold 长度、重复 BPM 行、乱序 BPM 必须规范化，不允许崩溃或生成负时间。
6. **作者花活保留原则**：普通高 BPM、正常的中途低 BPM、BPM 急变继续按原谱运行；只修异常边界，不把所有变速粗暴拉平成常速。

## 阶段 1：建立谱面异常规则与回归样本

### Task 1：真实曲库异常扫描

**验收条件：**
- 输出当前 5300+ 个 DIY JSON 中低 BPM、高 BPM、百万 BPM、重复行、非法值、音频越界等分类统计。
- 每类至少保留一个真实样本路径供测试。
- 不修改任何歌曲原始文件。

### Task 2：解析器规则测试

**验收条件：**
- 末尾 0.001 BPM 不再产生千分钟总时长。
- 中途真实低 BPM 不被误删。
- 重复 BPM 行采用确定性“同一行最后有效值”。
- 非法 BPM、负 Hold、乱序行不会崩溃或产生非有限时间。
- 假音符不进入判定事件。

## 阶段 2：迁移原项目补丁

### Task 3：规范化 JSON BPM 与事件输入

**验收条件：**
- BPM 先过滤非有限/非正值，再排序、去重并补 0 拍起点。
- 行号、玩家、类型、Hold 长度有边界保护。
- 返回诊断信息，测试可判断应用了哪些兼容补丁。

### Task 4：分离事件时间轴与总时长时间轴

**验收条件：**
- 事件仍按作者原始 BPM 时间轴计算。
- 只有异常末尾极低 BPM 被从总时长估算中剔除。
- SugarFree 的解析总时长恢复到约 171 秒，而不是 1502 分钟。

### Task 5：音频边界与幽灵音符保护

**验收条件：**
- Gameplay 倒计时以有效音频流长度为准。
- 明显超过音频尾部的音符不计分。
- 正常尾部 Hold 有小幅容差，不被误删。
- 音频缺失时仍可安全使用解析时长，不产生 0 秒闪退。

## 阶段 3：头像原色修复

### Task 6：复现头像双重取样变暗

**验收条件：**
- 自动化渲染测试证明当前圆形头像 Shader 会改变中心像素 RGB。
- Gameplay 与 ESC 使用同一套可复用头像材质，不再各写一段字符串 Shader。

### Task 7：头像圆形遮罩只处理 Alpha

**验收条件：**
- Shader 只裁圆，不重复乘纹理颜色。
- Gameplay HUD 与 ESC 头像中心 RGB 与源图一致。
- 外部 PNG/JPG/WEBP 和默认头像均正常。
- 头像不受百连全屏金色 Bloom 的颜色污染；外框特效仍正常。

## 最终检查

- DIY 时长专项测试通过。
- Gameplay 运行态保护测试通过。
- Gameplay 视觉契约测试通过。
- ESC 用户信息契约测试通过。
- Godot 无头启动无脚本编译错误。
- 不启动长期服务，不保留后台进程。

## 完成结果

- 原项目双时间轴锁尾补丁已迁移：事件时间轴保留作者 BPM，总时长估算按 30 秒异常阈值排除末尾极低 BPM。
- JSON BPM 已增加排序、同行去重、非法值过滤、缺失起始 BPM 回填和兼容诊断。
- `isFaked` 音符已从判定/计分剥离，并输出安全渲染窗口元数据；`bpmSpeeds` 输出有界视觉脉冲元数据。
- Gameplay 以有效音频长度收口，并同步裁剪超长 Hold 的秒与拍边界。
- Gameplay 与 ESC 头像统一使用只裁圆、不重采样颜色的 Shader。
- 全库审计 5304 个 DIY JSON：解析错误 0、非有限时长 0、小时级异常 0、非有限事件 0；129 个谱面触发锁尾保护。

## 风险与控制

| 风险 | 控制方式 |
|---|---|
| 把作者故意的变速误判为垃圾 | 只清理非有限/非正值和“末尾造成至少 30 秒异常膨胀”的极低 BPM |
| 音频长度有编码误差 | 尾部保留 0.35 秒容差 |
| 假音符支持扩大实现范围 | 本轮先保证不参与判定与不制造异常；视觉压缩窗口按原项目元数据保留接口 |
| 头像修复破坏圆形裁切 | 像素级离屏渲染测试同时检查圆外透明和圆内原色 |
