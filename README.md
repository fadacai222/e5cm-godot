# E5CM

E5CM 是一个使用 Godot 4.6.2 重制的 Windows 舞蹈节奏游戏项目。

## 当前版本

- 版本：`0.9.1`
- 平台：Windows x64
- 便携版：`release/E5CM/E5CM.exe`
- 安装包：`release/E5CM-Setup-0.9.1.exe`
- 兼容启动器：`release/E5CM/E5CM-Compatibility.bat`（老显卡、虚拟机或远程桌面）
- 默认安装位置：`%USERPROFILE%\Documents\E5CM`
- 安装后自动创建当前用户桌面快捷方式

## 精选曲库

发行版没有打包完整 51GB 曲库，而是使用固定随机种子从每个真实可玩子模式中保留最多 4 首歌：

- 真实可玩子模式：11 个
- 精选歌曲文件夹：44 个
- 精选曲库大小：约 221MB
- `竞速/情侣`、`花式/情侣` 的源目录只有空谱面占位且没有音频，因此发行版不显示这两个无效模式

完整曲库继续保留在项目根目录 `songs/`，构建过程只读使用，不移动、不替换；开发版完整索引保留在 PCK 中，发行版通过 EXE 同目录的 `release-song-index.json` 加载精选索引，构建中断也不会污染开发索引。歌曲内容不进入 Git 仓库，安装包只包含独立生成的精选曲库。

## 基本操作

| 操作 | 按键 |
|---|---|
| 投币 | `F` |
| 确认 / 进入 | `Enter` 或界面确认键 |
| 暂停 / 继续 | `Space` |
| 返回 / 菜单 | `Esc` |
| 自动播放 | `F6` |
| 击中音效 | `F7` |

完整流程：投币 → 选择玩家 → 登录 → 选择大模式 → 选择子模式 → 选歌 → 游戏 → 结算。

## 从源码导出

需要：

- Godot `4.6.2`
- 对应版本的 Windows 导出模板
- Inno Setup 6
- ImageMagick
- Python 3

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\打包发行版.ps1
```

脚本会自动完成：Windows 保留名文件清理、工具预检、每模式最多 4 首的独立发行曲库生成、Godot Windows 导出、开发索引完整性检查、默认与 OpenGL 兼容渲染器资产探针、Inno Setup 安装包编译、静默安装/双渲染启动/卸载烟雾测试，以及构建暂存清理。

`release/`、`.godot/`、完整歌曲内容和构建暂存不会进入 Git。大型核心媒体使用 Git LFS 管理。

## 显示与兼容性

- 首次启动默认 `144 FPS` 并开启垂直同步；设置菜单仍可切换到 `240 FPS`。
- 内部逻辑画布保持 `1920×1080`，窗口模式会根据当前显示器可用工作区等比缩放并居中，避免低分辨率或高 DPI 下超出屏幕。
- 默认启动失败时可运行 `E5CM-Compatibility.bat`，或从开始菜单选择“E5CM（兼容模式）”。
